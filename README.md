# hmclub

Product page and privacy policy for **Hattrick Manager Club**, a free, read-only CHPP app that
shows a Hattrick manager their own club on their phone.

**→ https://jcmoro.github.io/hmclub/**

- [Product page](https://jcmoro.github.io/hmclub/) — what the app shows and how it works
- [Privacy policy](https://jcmoro.github.io/hmclub/privacy.html) — what it does with your data

Static HTML, no dependencies, no trackers. The app itself lives in a separate repository.
